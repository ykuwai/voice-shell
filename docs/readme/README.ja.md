**声でClaude Codeに指示を出す。キーボードは要らない。**

作業しながら頭に浮かんだことをそのまま口に出せば、Enterキーを押さなくても
プロンプトとして届きます。テキスト欄に音声入力を貼り付けただけの仕組みとは
違います。ミュートも、聞き直しも、取り消しも、どのセッションに届けるかの
選択も、全部声だけで済ませられます。手は今やっていることに置いたままで
構いません。

## 💡 特徴

- **送るのに何も押す必要がありません。** たいていの音声入力ツールは、
  テキスト欄に文字を溜めて送信を押すのを待ちます。ここでは聞き取った瞬間に
  そのまま届きます。ボタンも、確認も、クリックして開くウィンドウも要りません。
- **試すのに何もインストールする必要がありません。** 既定の認識はブラウザが
  行うので、モデルのダウンロードも待ち時間もありません。ローカルだけで
  完結させたくなったら、設定をひとつ変えるだけでApple・Whisperの
  オンデバイス認識に切り替えられます。覚え直すことは何もありません。
- **マイクのアイコンだけの仕組みではありません。** ミュート、手直しと即時の
  切り替え、直前の取り消し、どのセッションに届けるかの選択、これも全部
  声でできます。詳しくは下の「声でできること」をご覧ください。画面には、
  聞き取った内容がそのまま伸びていきます。
- **複数の作業で同時に使えます。** 何セッションでも音声モードを立ち上げて
  おいて、どれに届けるかを画面からでも声からでも選べます。
- **聞き間違えた固有名詞は覚えさせられます。** 一度辞書に登録すれば
  （「クロードコード → Claude Code」）、以降はずっと直ります。認識している
  最中の文字にも反映されます。

## 📦 Voice Shellをインストール

```bash
pip install numpy aiohttp "sounddevice>=0.5.6"
npx skills add ykuwai/voice-shell -g -a claude-code -y
```

Chromeがあれば、これだけで動きます。`-g` を付けると `~/.claude/skills/` に
入るので、どのプロジェクトからでも使えます。1つのプロジェクトだけで
試したいときは、`-g` を外せば、そのプロジェクトの `.claude/skills/` だけに
入ります。`-a claude-code` は `npx` に判定させずClaude Codeと名指しし、
`-y` は本来聞かれる確認を省略します。

Claude Codeで `/voice-shell` と打つか、「音声モードにして」と言えば
始まります。そこから先の手順は
[SKILL.md](../../skills/voice-shell/SKILL.md) にあります。

## 🔄 Voice Shellをアップデート

```bash
npx skills update voice-shell -y
```

`-y` を外すと、先に確認が入ります。名前を外すと、入れているスキルを
すべてまとめて更新します。このスキルも含みます。

## 🔒 音声がどこへ行くか

3つのうち2つのやり方は、音声をこの機械の外へ一切送りません。切り替えは
設定ひとつで済みます。どのやり方が動いているかは、常に画面に表示されます。

> [!NOTE]
> 既定はブラウザの認識なので、音声はGoogleのサーバへ送られます。
> ローカルにとどめたいときは、画面の設定から選び直してください。画面の
> その場にも同じ注意が表示されます。

| やり方 | 何が要るか | 音声の行き先 |
|---|---|---|
| **このブラウザ**（既定） | Chrome。画面を開いている間だけ動きます | **Googleのサーバ** |
| Appleのオンデバイス | macOS 26以降。追加で入れるものはありません | ローカルだけ |
| Whisper | `faster-whisper`。固有名詞に強い | ローカルだけ |

選んだやり方は覚えているので、次回からはそのまま起動します。ローカルで
完結する2つの入れ方は
[SETUP.md](../../skills/voice-shell/SETUP.md) にあります。

認識できる言語は、選んだやり方によって決まります。ブラウザはChromeが
持つ一覧、AppleはOSに入っているロケール、Whisperはモデルの対応言語です。
画面の表示は7言語あります。

## 🗣️ 声でできること

何も付け加えず、この一言だけを言うと、すぐに切り替わります。

| 言うこと | 何が起きるか |
|---|---|
| 「ミュート」 | マイクが切れます |
| 「ミュート解除」 | マイクが戻ります（この機械のモデルが聞いているときだけです。ブラウザでは戻せません） |
| 「手直し」「エディット」 | ここから話した分は溜まるだけで、送られなくなります。送る前に直せます |
| 「即時」「そのまま送る」 | また、そのまま届く状態に戻ります |
| 「セッション2」「2番」 | 聞いているセッションが2つ以上あるとき、どれに届けるかを選べます |

話している文の終わりにこれを付け加えると、その一文だけに効きます。

| 言うこと | 何が起きるか |
|---|---|
| 「なかったことに」 | 直前に言った一文が、丸ごと捨てられます |
| 「あとで直す」 | 直前に言った一文が、送られずに下の欄へ回ります。送る前に直せます |

上に挙げた言い方は、どれも設定から切ることができ、自分の言い方を
教えることもできます。すべて画面の設定からです。7言語すべての
完全な一覧は、画面の電球アイコンの中にあります。
