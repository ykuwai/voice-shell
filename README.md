# voice-shell — 声で Claude Code に指示を出す

キーボードを使わずに、**話しかけて指示を出す**ための仕組み。

作業中に思いついたことをそのまま口に出せば、Enter を押さなくても届く。

```
マイク → 音声認識 → JSONL に1行 → Monitor → Claude Code
```

Claude Code のほか、Codex など他のエージェントからも使える。

## はじめかた

Claude Code で `/voice-shell` と打つか、「音声モードにして」と言う。以降は話すだけ。

**初回でも何も入れなくて動く。** 既定では Chrome に載っている認識を使うので、
モデルのダウンロードも待ち時間もない。

| 操作 | 動作 |
|---|---|
| 即時 | 話すとそのまま届く |
| 手直し | 溜めて、直してから送る |
| 一時停止 | 止めている間の発話はどこにも残らない |

止めるときは「音声モード終了」。

### 声だけで操作する

手が塞がっているときのために、いくつかの合図を聞いている。

| 言うこと | 起きること |
|---|---|
| ミュート / `mute` | マイクを切る |
| ミュート解除 / `unmute` | 戻す |
| 手直し / 溜めて / `hold` | 溜める側にする（直してから送る） |
| 即時 / `instant` | そのまま届く側に戻す |
| （文の最後に）キャンセル / 取り消し / `cancel` | その一言ごと送らずに捨てる |
| 2番目 / 2番 / 2に切り替え / 送信先2 / `switch to 2` | 2番目のセッションへ送る |

送信先の番号は、**ビューアの上に並ぶ順**（`1.` `2.` と出ている番号）。切り替えは
**マイクを切っている間も効く** — 切ったまま次の相手を決めておける。

**送信先の合図は、聞いているセッションが2つ以上あるときだけ効く。** ひとつしか
聞いていないときの「2番」は合図として扱わない（番号で答えただけの一言が消えない
ようにするため）。ただし短い返事は**最小文字数**（既定15字）で落ちるので、
そのままでは届かない — 番号だけで答えるときは一言添える。

数の言い方は認識のたびに揺れるので、読みを一通り見ている。「2」「二」「に」「ツー」
「トゥー」「two」はどれも 2 として拾う。**頭に数が来る言い方（「2番目」）が一番確実。**

合図と判定した発話は、**指示としては送られない**。何を合図として受け取ったかは
画面に出る（「『2番目』は合図として扱い、指示としては送っていません」）。

切り替わると短い音が鳴るので、画面を見ていなくても通じたか分かる。切るときは下がる音、
戻すときは上がる音、送信先が変わったときは2つの音、効かなかったときは低い音。

**その一言だけを喋ったときに限る。** 文の中で「ミュートして」「2に切り替えとか」と
言っても効かない。数字だけ（「2」「に」）でも効かない — 「に」は助詞と区別が付かず、
物音の誤認識で送信先が飛ぶとどこへ行ったのか分からなくなるため、「番」「番目」
「切り替え」「送信先」のどれかが要る。

崩れて聞こえるようなら、辞書に `ミュート回収 → ミュート解除` のように登録すれば拾う。

合図を聞くのは、手元のモデル（Apple / Whisper / Qwen3-ASR）を選んでいるとき。
切っている間も認識自体は動いていて、聞こえた内容を捨てているだけなので、解除の合図は
届く。**ブラウザ認識のときは使えない** — 切ると音声そのものを手放す作りにしてあり
（Google へ送り続けないため）、切った後の合図を聞く方法が無い。画面から戻す。

## 認識のやり方を選ぶ

ビューアの設定 →「認識するのは」から選ぶ。**入っていないものは出ない。**

| やり方 | 何が要るか | 音声の行き先 |
|---|---|---|
| **このブラウザ**（既定） | Chrome（画面を開いている間だけ） | **Google のサーバ** |
| Apple のオンデバイス | macOS 26 以降 | この機械の中だけ |
| Whisper | CPU でも動く。固有名詞に強い | この機械の中だけ |
| Qwen3-ASR | GPU 約12GB / Apple Silicon | この機械の中だけ |

**手元から音声を出したくない場合は、ブラウザ以外を選ぶ。** 画面のその場にも
同じ注意書きが出る。

選んだやり方は `~/.config/voice-shell/config.json` に残るので、**次からは
そのまま起動する**。使ったマイクも一緒に覚える。ブラウザを選んでいるときはモデルを積まないので、
`/voice-shell` と打った瞬間に使える状態になる。

```bash
voice-shell.sh engines              # 何が使えて、前回どれを選んだか
voice-shell.sh start --engine apple # 明示して起動する（次回も覚える）
```

## ビューア

**http://127.0.0.1:8090** — 認識中の文字がそのまま伸び、送った履歴が残る。

起動すると**独立したウィンドウ**（タブもURL欄も無い）で自動的に開く。
要らなければ `--no-gui` を付ける。

横にブラウザを並べずに済むよう、**手前に浮かぶ小窓**へ移せる（ヘッダのアイコン）。
Chrome の Document Picture-in-Picture を使うので、追加の実行環境は要らない。
常に最前面に来るので、他の作業をしながら認識の様子を見ていられる。

画面のまん中は**マイクの絵そのもの**で、拾えている音量の分だけ内側が下から光る。
囲みの輪は常に出ていて、そこが押せる範囲（＝ミュート）。切ると赤くなり、絵も
斜線入りに変わる。音量はブラウザ側でも同じマイクを開いて測っている。

### 未送信カード

いま認識している文字はここに出る。鉛筆を押すと**その一言だけ**溜めて、
直してから送れる（送り先は「即時」のまま。誤字を見つけたとき用）。

### 設定

歯車から開く。つまみを動かした時点で効く（再起動は要らない）。

| 項目 | 何を決めるか | 既定 |
|---|---|---|
| 認識するのは | 上の表のどれか | このブラウザ |
| マイク | 使う入力装置 | システムの既定 |
| 感度 | 0〜100。小さいほど微かな音まで拾う | 41 |
| 確定までの無音 | これだけ黙るとひと区切りにする | 1.5 秒 |
| 最小文字数 | これより短い結果は物音とみなして捨てる | 15 |
| 「えーと」を消す | つなぎ言葉を落としてから送る | 切 |
| テーマ / 言語 | 見た目 | 自動 |

**感度は自動調整できる。** 数秒喋って数秒黙ると、部屋の音と声の差から決める。
差が足りないときは値を決めず、マイクを近づけるよう伝える。マイクの下にある
オレンジの印をつまんで動かしてもよい。

「話しているのに何も届かない」ときは、まずこれを試す。

### ユーザー辞書

設定 → 辞書から、2種類のルールを登録できる。保存すると次の発話から効く。

| 種類 | 用途 | 例 |
|---|---|---|
| 言い換え | 誤認識しやすい固有名詞を直す | `クロードコード → Claude Code` |
| 無視する発話 | これ単独なら送らない | `チャンネル登録` |

実体は `~/.config/voice-shell/dictionary.json`。CSV で出し入れもできる。
公開したくない語は「手元だけに保存する」を使う（リポジトリに入らない）。

## 複数の作業で同時に使う

別々のことを並行して進めているとき、それぞれで音声モードを立ち上げておき、
**どれへ届けるかをビューアから選べる**。

聞いているセッションが2つ以上になると、画面の上に送信先が並ぶ。

```
[ 1. voice-shell のビューア刷新 ] [ 2. 認証まわりを直す ]
```

**既定は「あとで起動した方」。** 並行して別の作業を始めたら、そちらへ向くのが
自然なため。これはデーモンが決めるので、**画面を開いていなくても効く**。
押せば固定できる。声でも選べる（「2番目」）。

届くのは常にどれか1つで、**「全員へ」は無い**。2つのセッションが同じ指示を
受け取って別々に動き出す状況に使い道が無く、間違って選ぶと気づきにくいだけだった。

**名前は勝手に付く。** 最初はフォルダ名で、エージェントがその会話に題名を
付けた時点でそちらへ切り替わる。同じフォルダから2つ立てたときは `(2)` が付く。

| 道具 | 題名の在り処 |
|---|---|
| Claude Code | 記録の `ai-title` |
| Codex | `~/.codex/session_index.jsonl` の `thread_name` |
| そのほか | フォルダ名（`VOICE_SHELL_NAME` か `name` で名乗れる） |

```bash
voice-shell.sh name "認証まわりを直す"   # 表示名を手で付ける
voice-shell.sh name ""                   # 自動の題名に戻す
```

選んでいた相手が終了したら、画面で知らせて1つ前の生きているセッションへ移す。

## 誰が聞いているか確かめる

```bash
voice-shell.sh listeners
```

`listen` は止め忘れると生き続け、デーモンを入れ直してもつながり直す。実際に
**8日前のセッションが聞いたままで、同じ発話が2つのセッションへ配られていた**
ことがある。身に覚えの無いものが出たら止める。

送信先を選ばずに2つ以上が聞いていると、デーモンが発話ログに警告を書いて知らせる。

## セットアップ

**ブラウザの認識だけで使うなら、モデルは要らない。**

```bash
pip install numpy aiohttp
```

これと Chrome があれば動く。

手元で完結させたい場合だけ、下のどれかを入れる。詳しい手順は
[SETUP.md](skills/voice-shell/SETUP.md) にある。

| 環境 | 入れるもの |
|---|---|
| macOS 26 以降 | 何も要らない（OS 付属の認識を使う） |
| Windows / CPU のみ | `faster-whisper` |
| NVIDIA GPU | `vLLM` + Qwen3-ASR |
| Apple Silicon（macOS 25 以前） | `mlx-qwen3-asr` |

録音には `ffmpeg`（macOS / Windows）または `arecord`（Linux）が要る。

## 設定はどこに残るか

| 場所 | 中身 |
|---|---|
| `~/.config/voice-shell/config.json` | 使う認識のやり方 |
| `~/.config/voice-shell/tuning.json` | 感度・無音秒数・最小文字数など |
| `~/.config/voice-shell/dictionary.json` | ユーザー辞書 |
| ブラウザの localStorage | テーマ・波形・表示言語 |

いずれも再起動をまたいで残る。

## コマンド

```bash
voice-shell.sh start [--engine X] [--no-gui]   # 起動（前回の選択を覚えている）
voice-shell.sh stop                # 停止
voice-shell.sh status              # 稼働状況と、聞いているセッション
voice-shell.sh engines             # 選べる認識のやり方
voice-shell.sh listeners           # 聞いているセッションの一覧
voice-shell.sh name "…"            # このセッションの表示名
voice-shell.sh hold "理由" / live   # 溜める側へ回す / 戻す
voice-shell.sh viewer              # ビューアだけ起動
```

## 構成

```
skills/voice-shell/
├─ SKILL.md              エージェントが読む手順
├─ SETUP.md              環境ごとの導入
└─ scripts/
   ├─ voice-shell.sh     起動・停止・状態確認
   ├─ voice_daemon.py    常駐。認識して JSONL に書く
   ├─ asr_mic.py         マイクと発話の区切り（VAD）
   ├─ viewer.py          ビューアのサーバ
   ├─ viewer.html        ビューアの画面
   ├─ listen_filter.py   送信先で絞り込む
   └─ engine_*.py        認識エンジンごとの差分
```

## 認識できる言語

30言語 + 22中国語方言。`--language` は主に出力形式を固定するもので、認識できる
言語を制限しない（日本語固定でも英語を話せば英語で返る）。

ビューアの表示言語は認識する言語とは別で、英語と日本語を持つ。
